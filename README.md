# Bedrock

A boring grey-ish base theme that doesn't look fancy on its own, but provides
all the base styles and CSS classes, to start a custom design in your own
sub-theme.

[How sub-themes work](https://docs.backdropcms.org/documentation/creating-sub-themes)

## Installation

- Install this theme using the official [Backdrop CMS instructions](https://docs.backdropcms.org/documentation/skin-with-themes)
